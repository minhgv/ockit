16. Config & Bug Register

ISSUE-01 — Plugin ockit-ba-traceability.js crash do client undefined HIGH ✅ RESOLVED 2026-08-07

File: .opencode/plugin/ockit-ba-traceability.js:23,41

What: Export async () (không tham số) nhưng body gọi await client.app.log(...). client không có trong scope.

Impact: Mỗi lần agent edit/write file khớp pattern spec doc (spec|prd|rtm|edge-case|tlgp), hook after ném ReferenceError: client is not defined → log lỗi hoặc break tool chain. Compare ockit-tdd-runner.js đúng dùng async ({ client }) destructure (dù không dùng), còn plugin này quên inject.

Fix: Đổi signature async ({ client }) => ({ "tool.execute.after": async (input) => { ... } }) — hoặc bỏ client.app.log nếu OpenCode runtime không inject client cho hook tool.execute.after. Verify contract plugin signature với @opencode-ai/plugin@1.14.40.

✅ Fix applied (2026-08-07): Wrapped client.app.log(...) trong if (client?.app?.log) { try { await ... } catch {} } — logging best-effort, không bao giờ throw (Constitution Art.7.3). Mirror đồng bộ sang src/ockit/templates/plugin/ockit-ba-traceability.js (byte-identical, R-003). Guard bởi tests/unit/test_plugin_smoke.py::test_r001_ba_traceability_no_throw_without_client + test_r002_all_plugins_export_valid_hook_shape. Xem plans/SPEC_top3_risk_fixes.md (R-001, R-002, R-003).
